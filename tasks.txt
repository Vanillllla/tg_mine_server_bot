Сначала изучи проект и его стиль, затем преступай к задаче сохраняя стилистику проекта и меняя изначальный код минимально:

Создай в проекте базу данных(sqlLite) пользователей.
Названиие : Users
Столбци :
```
id (уникальный, int, автоматических)
status (int, по умолчанию 1)
tg_id (уникальный, int)
tg_nickname (строка)
game_nickname (строка)
```

Также создай в папке @C:/Users/ivanm/PycharmProjects/tg_mine_server_bot/app/core файл для работы с базой. Там должны быть функции для удоного запроса данных из базы данных. Необходимые функции:
db.get("", "", "") - получить по первому пареметру(название первого столбца) второй(названиие столбца) третий(сами данные первого элемента), выдаёт занчениие эмемента столбца.
db.getlist("", "") - получить по первому пареметру(название первого столбца) второй(сами данные первого элемента), выдаёт всю строку в виде словоря.
db.getall() - выдаёт всю базу данных в виде двумерного словоря без заголовков колонок.
db.getnames() - просто принтует описание для обращения к двумернму массиву.

db.set("tg_id", "status", "...", "...", ...) - создаёт новую строку в таблице с данными введёнными в параметры функции по порядку, если "", None или не введён вообще то ячека создаётся пустой.
db.change("col", "data1", "col_chenge", "data2") - меняет c col_chenge в строке где col - data1 на data2

Все входные параметры должны переводиться к нужному в базе данных типу данных.

Также сделай оброботчик ошибок, в случае ошибок функция возвращает ничево в нужном типе данных, тоесть 0 или "".
А затем принтует ошибку, проблема входных данных или отсутствие данных или ещё чтото в звисимости от ситуации.
