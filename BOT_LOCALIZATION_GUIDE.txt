Как добавлять кнопки и сообщения с локализацией

1. Кнопки
- Общий файл клавиатур: app/services/bot_keyboard.py
- Тексты кнопок лежат в BUTTON_TEXTS_BY_LOCALE:
  - "ru" для русского
  - "en" для английского
- Раскладка кнопок лежит в KEYBOARD_LAYOUTS и задаётся через ID кнопок, а не через текст.

Пример добавления новой кнопки:
1. Добавь новый ID в BUTTON_TEXTS_BY_LOCALE["ru"] и BUTTON_TEXTS_BY_LOCALE["en"].
2. Добавь этот же ID в BUTTON_ACTIONS в app/services/bot_ui.py.
3. Вставь ID кнопки в нужную раскладку в KEYBOARD_LAYOUTS.
4. Обработай действие этой кнопки в app/services/telegram_bot.py.

Пример:
- В bot_keyboard.py:
  - "stats": "📈 Статистика"
  - "stats": "📈 Stats"
- В bot_ui.py:
  - "stats": "stats"
- В KEYBOARD_LAYOUTS:
  - ["online", "stats"]

2. Сообщения
- Общий файл сообщений: app/services/bot_locale.py
- Тексты сообщений лежат в MESSAGES_BY_LOCALE:
  - "ru" для русского
  - "en" для английского
- Ключ сообщения должен быть одинаковым для обоих языков.

Пример добавления нового сообщения:
1. Добавь ключ в MESSAGES_BY_LOCALE["ru"].
2. Добавь тот же ключ в MESSAGES_BY_LOCALE["en"].
3. Получай сообщение через get_message(...) или self._msg(...) в telegram_bot.py.

Пример:
- В bot_locale.py:
  - "stats_text": "📈 Статистика сервера: {value}"
  - "stats_text": "📈 Server stats: {value}"

Использование:
- get_message(locale, "stats_text", value=123)
- self._msg(message, "stats_text", value=123)

Важно
- Не вставляй текст кнопок и сообщений напрямую в код обработчиков.
- Всегда используй ID/ключ, а сам текст храни в словарях локализации.
- Если ключа нет в выбранном языке, bot_ui.py возьмёт fallback из русского языка.
